# Lucky Chips

Casino de fichas ficticias (sin dinero real): tragamonedas, blackjack, ruleta, minas, sigue la bola, apuestas deportivas y sobres sorpresa. Diseñado para jugarse desde el celular.

> **Importante:** la Liga de Amigos y el Poker en línea usan la base de datos en vivo de Claude y **no funcionan** en esta versión publicada en GitHub Pages. Esas dos secciones muestran un aviso con un botón para abrirlas en Claude. Todo lo demás (tragamonedas, blackjack, ruleta, minas, sigue la bola, apuestas deportivas y sobres) funciona igual aquí.

## Cómo publicarlo en GitHub Pages (sin usar la terminal)

1. Entra a [github.com](https://github.com) con tu cuenta y crea un repositorio nuevo (botón verde "New").
   - Ponle un nombre, por ejemplo `lucky-chips`.
   - Déjalo **público** (GitHub Pages gratis solo funciona en repos públicos).
   - No marques ninguna otra opción, solo crea el repositorio vacío.
2. En la página del repositorio recién creado, busca el enlace que dice **"uploading an existing file"** (o ve a la pestaña *Add file → Upload files*).
3. Arrastra ahí estos 5 archivos que te envié: `index.html`, `manifest.json`, `icon-192.png`, `icon-512.png`, `icon-180.png`. Espera a que suban y dale a **Commit changes**.
4. Ve a **Settings → Pages** (en el menú de la izquierda).
5. En "Build and deployment" elige **Deploy from a branch**, rama **main**, carpeta **/ (root)**, y dale **Save**.
6. Espera 1-2 minutos. GitHub te va a mostrar un enlace como `https://TU-USUARIO.github.io/lucky-chips/` — esa es tu app publicada.

Desde el celular, abres ese enlace y usas "Agregar a pantalla de inicio" en el navegador para que quede como un ícono de juego, igual que con el enlace de Claude.
